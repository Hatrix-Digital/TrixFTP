How it works

Everything you do with a server, in one window

1

Connect

Quick Connect bar, Site Manager (F8) or stored bookmarks. FTP, FTPS with TLS and SFTP are first-class citizens; passwords are encrypted with the OS credential store.

2

Browse and sync

Two panes, tabs per session, full file info and filters. Compare directories, keyboard type-ahead and drag and drop between sides and from the operating system.

3

Transfer without babysitting

Queue handles 1-6 parallel jobs with pause, resume, retry and speed limits. If a session dies mid-queue, jobs re-attach or reconnect automatically.

Features

Built like a serious FTP tool

Dual-pane browser

Local and remote side by side. Sorting, filtering, hidden files, multi-select, directory compare with difference highlighting.

Transfer queue

Up to 6 parallel transfers, pause all, resume all, retry failed, live speed and ETA for every job.

Auto-reconnect

A dropped session never fails a queued job: the queue re-binds to any live session or opens a fresh one with saved credentials.

Encrypted site manager

Bookmarks for unlimited hosts. Passwords protected by OS storage (DPAPI on Windows, keychain elsewhere).

Resume and integrity

Interrupted transfers continue through REST/size offset; finished files are verified against the listing size.

Conflict policies

Overwrite, skip, resume or rename - per file or "apply to all", with a clear size and date comparison dialog.

Speed limits

Throttle transfers in KB/s so production servers and public hotspots stay usable during uploads.

Keyboard first

Type-ahead jump-to-letter in both panes, F5 refresh, F8 site manager, Ctrl+S / Ctrl+T / Ctrl+W tab control.

FAQ

Common questions

Is TrixFTP free?

Yes. It is open source under the MIT license - use it personally or commercially, view and modify the code freely.

Why does Windows show "unknown publisher"?

Installers are built in CI but not code-signed (a paid certificate is required). Choose "More info - Run anyway". Or build locally from source.

Where are my site passwords stored?

Encrypted with the operating system credential store (Windows DPAPI, macOS keychain, Linux libsecret via Electron safeStorage). Init files are never plain text.

What happens when the server drops my connection mid-queue?

Nothing dramatic: the remaining jobs automatically re-attach to a live session for the same host, or open a new connection using the stored site settings. Interrupted files resume from the byte offset.

Does it support both FTPS and SFTP?

Yes - FTP with explicit TLS (FTPS) and SSH File Transfer Protocol (SFTP v3) including key based authentication. Plain FTP is also supported where allowed.
